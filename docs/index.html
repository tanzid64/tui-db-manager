Designed for Reliability & Privacy

Why Developers & DevOps Choose dbk

🔒

Zero Plaintext Secrets

Database credentials, S3 secret keys, and bot tokens are stored in an encrypted local vault (secrets.enc) using Argon2id key derivation and AES-256-GCM authenticated encryption.

🛡️

Client-Side Age Encryption

Backups can be streamed directly into modern age (X25519) encryption before uploading. Unattended servers only need the public recipient key; your private keys stay cold.

🔍

Live Database Discovery

When configuring MySQL or PostgreSQL, dbk dynamically discovers databases on the host and lets you pick from a menu instead of memorizing and manually typing catalog names.

☁️

Native Multi-Cloud Sync

Stream directly to Google Drive (Service Account), Cloudflare R2 (zero egress fees), AWS S3, MinIO, Wasabi, Backblaze B2, or local/NFS mounts with automatic retention pruning.

⏰

OS-Native Scheduler

No memory-leaking background daemon. Registers headless scheduled jobs directly with systemd timers, UNIX cron, or Windows Task Scheduler with 1 click.

🚀

In-Place Self-Updater

Detects new GitHub releases in the background, alerts you with a modal in the TUI, verifies SHA-256 digests against checksums.txt, and safely replaces the binary in-place.

High Efficiency Pipeline

How the dbk Engine Works

Memory-bounded Unix pipe streaming: never buffers multi-gigabyte databases entirely into RAM.

1 DB Dump mysqldump, pg_dump, mongodump, vacuum
2 Compress Streaming Gzip (CPU friendly)
3 Age Encrypt X25519 envelope cipher
4 Cloud Sync S3, R2, GDrive & prune

Official Configuration Guide

How to Set Up Cloud Storage Providers

Step-by-step instructions to obtain API keys and service credentials for your preferred storage destination.

Google Drive SetupService Account

No interactive browser login required. Unattended, robust, and headless.

📁
1
Create a Google Cloud Project:

Go to Google Cloud Console, click the project selector, and click New Project (e.g. dbk-backups).

2
Enable the Google Drive API:

Navigate to APIs & Services > Library. Search for Google Drive API, select it, and click Enable.

3
Create a Service Account & Download Key:

Go to Credentials > Create Credentials > Service Account. Name it dbk-backup-agent and finish.

Open the service account > Keys tab > Add Key > Create new key > JSON. This downloads your service account JSON file.

4
Share Target Folder with the Service Account:

Copy the service account email (dbk-agent@your-project.iam.gserviceaccount.com).

Open Google Drive, create a folder, right-click > Share > paste the service account email with Editor permission.

5
Grab the Folder ID:

Open the shared folder in your browser. Copy the ID at the end of the URL:

https://drive.google.com/drive/folders/1A2B3C4D5E6F7G8H9I0JKLMNOP
Adding into dbk:

# 1. Via TUI: Open dbk → Storage → Press 'a' → Select 'gdrive'

# 2. Paste Folder ID & Service Account JSON (stored securely in vault)

dbk secret set storage/gdrive/credentials --stdin < service-account.json

Cloudflare R2 SetupZero Egress

100% S3-compatible API with zero data transfer/egress fees.

⚡
1
Create an R2 Bucket:

In the Cloudflare Dashboard, go to R2 Object Storage > Create bucket (e.g. dbk-production-backups).

2
Generate R2 API Tokens:

On the R2 overview page, click Manage R2 API Tokens.

Click Create API Token > Permissions: Object Read & Write > select your bucket > Create API Token.

3
Note Down R2 Credentials:

Copy the Access Key ID, Secret Access Key, and the S3 API endpoint URL:

Endpoint: https://<ACCOUNT_ID>.r2.cloudflarestorage.com
dbk Storage Configuration:

Type: s3

Bucket: dbk-production-backups

Region: auto

Endpoint: https://<ACCOUNT_ID>.r2.cloudflarestorage.com

Access Key ID: <YOUR_R2_ACCESS_KEY>

Secret Key: [stored encrypted in dbk vault]

Amazon AWS S3 SetupIAM Restricted

High durability, cross-region replication, and lifecycle policies.

🪣
1
Create S3 Bucket:

In AWS Console open S3 > Create bucket (e.g. my-company-db-backups) in your region (e.g. us-east-1).

2
Create Dedicated IAM User:

Go to IAM > Users > Create user (e.g. dbk-backup-worker).

Attach a scoped inline policy for your bucket only:

s3:PutObject, s3:GetObject, s3:DeleteObject, s3:ListBucket
3
Generate Access Keys:

User details > Security credentials > Create access key > CLI. Copy the Access Key ID and Secret.

dbk Storage Configuration:

Type: s3

Bucket: my-company-db-backups

Region: us-east-1

Endpoint: (leave empty for default AWS S3)

Access Key ID: AKIAIOSFODNN7EXAMPLE

Secret Key: [stored encrypted in dbk vault]

MinIO (Self-Hosted S3)Private Cloud

High-performance S3 object storage on your own hardware or Kubernetes.

🏢
1
Create Bucket in MinIO Console:

Open your MinIO Console (e.g. https://minio.internal:9001), go to Buckets > Create Bucket (e.g. backups).

2
Generate Service Access Key:

Go to Access Keys > Create Access Key. Copy the generated Access Key and Secret.

3
Configure Endpoint in dbk:

Use your S3 API endpoint port (typically 9000):

Endpoint: https://minio.yourcompany.com:9000 (Region: us-east-1)

Backblaze B2 SetupAffordable S3

S3-compatible storage with simple, low storage costs.

📦
1
Create B2 Bucket:

In Backblaze B2 > Buckets > Create a Bucket (e.g. my-db-backups). Note the Endpoint (e.g. s3.us-west-004.backblazeb2.com).

2
Create Application Key:

Go to App Keys > Add a New Application Key. Grant Read and Write to your bucket. Note keyID and applicationKey.

Engine Diversity

Supported Database Engines

Tailored wizards that ask only for engine-relevant configuration.

PostgreSQL

pg_dump / Custom Formats

Automatic discovery of all databases on the PostgreSQL server. Supports standard SQL streams or custom archive format. TLS enabled.

MySQL & MariaDB

mysqldump / Quick Streaming

Auto-discovers schemas. Streams single-transaction consistent dumps with compression directly to target storage backends.

MongoDB

mongodump / Archive Stream

Connects via host/port or URI. Streams BSON archives for full collections, indexes, and metadata without intermediate disk usage.

SQLite

Zero Server / Safe Vacuum

Single-field path wizard: only asks for the database file path. No host, user, or port fields. Safe consistent backup copies.

Automate Everything

CLI Command Cheat Sheet

Run headless in cron jobs, CI/CD pipelines, Docker containers, or scripts.

dbk

Launches the full interactive Bubble Tea TUI interface

Interactive
dbk run <job-name>

Runs on-demand headless backup for a job and exits (pass --quiet --json for scripts)

Headless CLI
dbk restore <job-name>

Interactively lists historical backup snapshots and safely restores into target database

Disaster Recovery
dbk schedule install <job-name> --at "0 2 * * *"

Registers unattended backup timer with OS scheduler (systemd timer, cron, or Task Scheduler)

OS Scheduling
dbk update

Checks GitHub for newer releases, verifies SHA-256 digest, and atomically upgrades binary in-place

Self-Updater
dbk config export --encrypt-with-passphrase

Exports full configuration and vault secrets into an encrypted portable transfer bundle
